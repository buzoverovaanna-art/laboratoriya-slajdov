# Отчёт: дипломный проект «Лаборатория слайдов»

Составлено 21.09.2026 по итогам рабочей сессии. Все данные взяты из проделанной работы; чего нет или что не проверено — так и написано.

## 0. Коротко

- **Что это.** Приложение для школьниц: ученица выбирает, кто делает презентацию, предмет, тему (или вставляет текст, фото, файлы), число слайдов и стиль — и через 30–60 секунд получает готовую презентацию в одном HTML-файле, с именем на первом слайде, шпаргалкой выступления, всплывающими фактами и ссылками на источники.
- **Для кого.** Две дочери Анны (7 и 8 класс). Устанавливается значком на экран планшета, работает по домашнему Wi-Fi.
- **Как сделано.** «Вайб-кодингом» с Claude Code: Анна ставила цель и принимала решения, Claude Code писал и проверял код.
- **Итоги в цифрах.** 4 стиля оформления, 6 раскладок слайдов, до 20 слайдов, 2 режима материала, около 2 400 строк Python + 235 строк HTML + 162 строки CSS + 53 строки Swift (без сторонних библиотек).
- **Расходы: 0 ₽.** ИИ — бесплатный тариф GigaChat (Сбер), поиск — бесплатный Serper. Платный Claude API не использовался.
- **Игра:** внутри презентации — «Игра для класса» (две команды отвечают на вопросы, которые пишет ИИ). Первые версии отчёта (21.09) называли две игры, «Дуэль» и «Загадай желание»: позже их убрали, осталась одна.
- **Обновление 24.09.2026:** стилей по-прежнему четыре, но состав другой — Harry Potter, Genshin Impact, Brawl Stars, Business (Toca Boca 22.09 сняли с полки: «слишком по-детски»). Добавлены PDF для сдачи учителю и README со скриншотами.
- **Не готово для сдачи:** публикация на GitHub и скилл проекта (см. разделы 9 и 12). README и PDF сделаны 24.09.

## 1. Проблема и идея

Школьные презентации в 7–8 классе — выбор из двух плохих вариантов: скучный шаблон PowerPoint или самодельный «мем-ужас», который стыдно показать учителю. Вечера на них уходят у детей и родителей.
Идея: инструмент, который делает презентацию **и красивой, и живой**, а ребёнок сам выбирает стиль — от делового до любимых игр.
Формулировка боли для подачи: «школьная презентация без слёз — за 2 минуты вместо вечера всей семьи».
Проект взят из реальной жизни автора (две школьницы дома), а не из готового списка курса — так Анна отбирала идею (варианты «Советник», «фокус-группа» и др. отложены или отклонены).

## 2. Как я работала (метод)

- **Роли.** Анна — заказчик и автор решений; Claude Code (модель Claude Sonnet 5) — разработчик, исследователь и тестировщик.
- **Цикл работы.** Claude Code предлагал план → Анна отвечала «да» или меняла → Claude Code делал → показывал результат (снимки экрана, страница в браузере, «было/стало») → Анна правила словами и присылала образцы-картинки.
- **Правила Анны, по которым шла работа:** объяснять просто и коротко; сначала план, потом «да» для больших задач; ничего не удалять без подтверждения; личные данные учениц не класть в файлы, уходящие в интернет; в Git отправлять только по команде; факты не выдумывать — если данных нет, так и говорить.
- **Контроль качества.** Каждый этап проверялся: снимки экрана всех раскладок во всех стилях, автоматические проверки, настоящий браузер (Playwright), живые запросы к ИИ. Найденные ошибки исправлялись сразу (раздел 5).

## 4. Что переделывали (повороты и решения)

1. **Название:** «СмехоСтудия» и другие варианты → «Презентации» → **«Лаборатория слайдов»**.
2. **Стили:** сначала три (На урок, Мем-шоу, Терминал) → четыре по играм девочек. «Мем-шоу» и «Терминал» остались в коде запасными.
3. **Названия карточек:** русские («Геншин», «Тока Бока») → оригинальные «Genshin Impact», «Toca Boca» (Анна: «чтобы было эпично»). Логотипы и персонажей игр не используем — только «в стиле».
4. **Главная страница:** простая → три варианта на выбор («Изумруд», «Редакция», «Неон») → «Неон» смягчён и всё равно отклонён → ещё три («Лес», «Природа», «Красный») → **выбрана «Природа»** (светло-зелёная рамка, нарисованные иллюстрации). Остальные варианты убраны.
5. **Экран создания:** «тема + стиль» → 5 шагов: ученица → предмет → материал → число слайдов → стиль.
6. **Предмет:** кнопки (история, география…) плюс «свой предмет»; выводится на первом слайде.
7. **ИИ:** платный Claude → выяснили, что нужен VPN и оплата → **GigaChat (Сбер)**: бесплатно, 365 млн токенов до 21.09.2027, из России без VPN. Claude оставлен запасным вариантом в коде.
8. **Режимы материала (три поворота):**
   - идея «по учебнику из интернета» → проверили на практике: находятся чужие сканы, «ГДЗ», платные библиотеки → **отклонено**;
   - оставить два режима: «Своя тема — найди сам» и «Вставлю текст сама»;
   - в «Вставлю текст» добавлен **плюсик для фото, PDF, Word, TXT** (Анна: «чтобы можно было добавлять из своих файлов и фотографий»);
   - поиск сначала шёл только по проверенным сайтам → по просьбе Анны **по всему интернету** с фильтром мусорных сайтов.
9. **Честность ИИ:** после первого настоящего запуска GigaChat выдумал цитату, «цифру» и название учебника — добавлены запреты и проверки в коде (раздел 5).
10. **Удаление:** только окончательное, с подтверждением («мягкое» — отклонено).

| В старом стиле «Терминал» ошибка записи, из-за неё не запускалось всё приложение | Проверка запуска перед началом работы | Исправила запись в файле стиля |

## 7. Как устроено приложение

Поток данных при создании презентации:

1. **Форма** (`templates/_app.html`): ученица, предмет, источник материала, число слайдов, стиль.
2. **Материал.** Режим «Своя тема»: `research.py` ищет через Serper по всему интернету, отсеивает мусорные сайты (ГДЗ, видео, соцсети, магазины и др.), читает 2–4 страницы. Режим «Вставлю текст или фото»: `extract.py` + `ocr.swift` достают текст из фото, PDF, Word и TXT (файлы сразу удаляются).
3. **Сценарист** (`ai.py`): GigaChat пишет структуру презентации строго по схеме (JSON) по правилам — честность, заголовки-выводы, шпаргалка, факты для всплывающих окон. Код проверяет цитаты и цифры по материалу и подставляет источники сам.
4. **Движок** (`styles/engine.py`) + «паспорт» выбранного стиля собирают **один HTML-файл**: раскладки одинаковы во всех стилях, отличаются цвета, шрифты, украшения, переходы, эффекты.
5. **Полка «Мои работы»**: открыть или удалить.

Файлы проекта: `app.py` (сервер), `ai.py`, `research.py`, `extract.py`, `generator.py`, `ocr.swift`, `styles/` (движок, 4 стиля + 2 запасных), `templates/`, `static/`, `students.example.json`, `requirements.txt`. Личное (`students.json`, `usage.json`, `ai-errors.log`, папка `works/`, собранная программа `ocr`) внесено в `.gitignore`.

## 14. Как запустить

```
cd ~/Documents/my-projects/diploma-project/prezentacii
.venv/bin/python -u app.py
```
Команда печатает два адреса: для компьютера (`http://localhost:5050`) и для планшета в той же сети Wi-Fi (`http://<адрес>:5050`). На планшете: «Поделиться» → «На экран „Домой“». Остановить: Ctrl+C.
Для ИИ нужны ключи в `~/.config/klyuchi-zakrytye/`: `gigachat.key` (основной), `serper.key` (поиск), сертификат `russian_trusted_root_ca.pem`. Без ключа GigaChat приложение делает демо-презентации с заготовками. Сбои ИИ записываются в `ai-errors.log`.
