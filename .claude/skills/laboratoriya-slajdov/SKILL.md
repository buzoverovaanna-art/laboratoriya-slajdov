# Лаборатория слайдов

Приложение для дочерей Анны (7 и 8 класс): выбрать ученицу, предмет, тему или свой текст, число слайдов и стиль — через минуту готова презентация в одном HTML-файле. Сервер на MacBook Анны, планшеты подключаются по домашнему Wi-Fi.

Код лежит в корне репозитория. Описание и решения: `docs/2026-09_diplomnyy-proekt_prezentacii_opisanie.md`, отчёт для диплома: `docs/2026-09_diplomnyy-proekt_otchet.md`, список доработок: `docs/2026-09_pravki.md`. Перед большой правкой прочитай нужный из них, а не пересказывай по памяти.

## Правила (они важнее любых удобств)

- **Имена девочек — личные данные.** Они лежат только в `students.json` (он в `.gitignore`). Не пиши их в файлы, отчёты, скриншоты и запросы к ИИ. Для снимков подменяй имена выдуманными из `students.example.json` прямо в браузере.
- **В GitHub — только по команде Анны.** Перед `git add/commit/push` покажи `git status` и проверь файлы на личное. Не делай репозиторий публичным без её «да».
- **Файлы Анны не удалять без подтверждения.** Перед пересборкой готовых работ копируй их во временную папку вне репозитория.
- **Не создавай папки без спроса**, файлы клади только по названному адресу.
- **Не гоняй проверки по кругу** — экономь лимит. Если проверка прошла, не повторяй её.
- Игра теперь одна — «Игра для класса» (`games.py`). «Дуэль» и «Загадай желание» убраны, не возвращай. Стилей четыре: Harry Potter, Genshin Impact, Brawl Stars, Business; Toca Boca снят с полки (лежит в `LEGACY_STYLES`), не возвращай без Анны.
- Язык презентаций — только русский. Имя ученицы не должно попадать в запрос к ИИ.

## Запуск

```bash
cd <папка проекта>
.venv/bin/python -u app.py          # порт 5050; адрес для планшета печатается при запуске
pkill -f "python -u app.py"         # остановить
```

Ключи вне проекта, в `~/.config/klyuchi-zakrytye/`: `gigachat.key` (основной ИИ), `russian_trusted_root_ca.pem`, `serper.key` (поиск), `anthropic.key` (запасной, платный). Без ключей приложение делает демо-презентацию с заготовками. Содержимое ключей не читай и не показывай. Причины сбоев ИИ — в `ai-errors.log`.

## Частые задачи

**Пересобрать готовые работы после правки движка или стилей.** Скрипт слайдов запечён в каждый HTML, поэтому старые работы сами не обновляются. Данные хранятся в `.json`, ИИ не нужен:
```python
import generator
for m in generator.list_works():
    generator.update_work(m["id"], generator.load_deck(m["id"]))
```
Сначала скопируй HTML во временную папку вне репозитория. Кэш PDF (`works/*.pdf`) обновится сам, если HTML новее; при смене `pdf.py` удали старые `works/*.pdf` (это кэш).

**PDF.** Кнопка «PDF» на полке или `GET /pdf/<имя>.html`. Нужен Google Chrome. Лист задаём сами (1280×720): стандартный лист включает телефонную раскладку. Слайд, не влезающий в лист, чуть уменьшается.

**Проверить вёрстку.** Открой работу в браузере (Playwright MCP, файлы по `file://` не открываются — подними `python3 -m http.server` в папке-времянке) и пройди все слайды на размерах 1280×720, 1024×768, 1180×820, 820×1180, 1920×1080. Признак беды: у активного слайда `scrollHeight > clientHeight`. На ширине ≤ 640 px (телефон) прокрутка допустима. Ссылка `#N` должна открывать N-й слайд.

**Скриншоты для README.** Приложение запусти, размер окна 1200×800, в браузере замени имена на выдуманные, сохрани в `readme-screens/`, потом убедись, что настоящих имён на странице нет. Останови сервер.

**Новый стиль.** Файл `styles/<имя>.py` с «паспортом» (цвета, шрифты, переходы) и функцией `render`, регистрация в `generator.STYLES`, карточка в форме. Снимки всех 6 раскладок в новом стиле — перед тем как показывать Анне.

## Известные ограничения

- GigaChat (бесплатный) отвечает одним потоком и имеет лимит токенов (`usage.json`); девочки не должны создавать презентации одновременно.
- Поиск картинок иногда приносит подписи со стоков и мемы на серьёзные темы — в `docs/2026-09_pravki.md`, пункт Б4.
- Claude как запасной ИИ проверен только «вхолостую».
- Факты от ИИ и из интернета могут быть неточными; приложение просит сверять с учебником.
